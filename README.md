# ✂️ 快捷截图工具
单个EXE文件，无需安装
一个轻量级、功能齐全的快捷截图工具，支持自动识别窗口截图、区域截图、放大镜、取色、取坐标等功能。截图方式类似微信截图，自动识别窗口或者框选截图
新增空格+左键框选滚动截屏

## 功能特性
- ⭐ **启动图标** - 启动程序仅打开右下角程序图标,点击图标截图
- ⌛ **开机自启** - 右键托盘图标，可设置开机自启
- 📸 **区域截图** - 支持鼠标框选截图区域
- 🖥️ **窗口截图** - 自动识别当前活动窗口并截图
- 🎯 **滚动截图** - 轻量Pillow (PIL)库实现的简易滚动截图
- 📋 **一键复制** - 截图后自动复制到系统剪切板
- 🖼️ **自动保存** - 可选择自动保存截图到程序目录
- 🔍 **放大镜功能** - 鼠标悬停显示局部放大预览，显示坐标和颜色
- 🎨 **坐标|取色** - 右键取消截图并复制像素颜色值和坐标到剪切板

## 快速开始

### 安装依赖

```bash
pip install -r requirements.txt
```

### 运行程序

```bash
python main.py
```

### 打包为 EXE

```bash
python build.py
```

打包后的可执行文件位于 `dist/ScreenshotTool.exe`

## 使用说明

### 截图操作

1. **截图**：点击界面上的"点击截图"按钮
2. **框选区域**：在屏幕上按住鼠标左键拖动选择区域
3. **完成截图**：松开鼠标左键，截图自动保存到剪切板

### 取色功能

- **鼠标悬停**：显示局部放大镜，可查看像素细节
- **右键操作**：右键点击可复制当前坐标和色值信息

### 其他功能

- **自动保存**：勾选"自动保存"复选框，截图自动保存到程序目录
- **拖动窗口**：按住主窗口任意位置可拖动窗口位置
- **滚动截屏**：按住空格+左键框选，实现滚动截图, 使用Pillow (PIL)进行行像素匹配
