# ✂️ 快捷截图工具
单个EXE文件，无需安装
一个轻量级、功能齐全的快捷截图工具，支持自动识别窗口截图、区域截图、放大镜、取色、取坐标等功能。截图方式类似微信截图，自动识别窗口或者框选截图。
新增空格+左键框选滚动截屏

## 功能特性
- ⭐ **启动图标** - 启动程序仅打开右下角程序图标,点击图标截图
- ⌛ **开机自启** - 右键托盘图标，可设置开机自启
- 📸 **区域截图** - 支持鼠标框选截图区域
- 🖥️ **窗口截图** - 自动识别当前活动窗口并截图
- 🎯 **滚动截图** - 实现的简易滚动截图
- 📋 **一键复制** - 截图后自动复制到剪切板
- 🖼️ **自动保存** - 可选择自动保存截图到程序目录
- 🔍 **放大镜功能** - 鼠标悬停显示局部放大预览，显示坐标和颜色
- 🎨 **坐标|取色** - 右键取消截图并复制像素颜色值和坐标到剪切板
- ✏️ **截图后编辑** - 截图后可进行矩形框、画笔、文字标注，支持调节粗细/字体大小

### 截图操作

1. **截图**：点击右下角图标或程序界面上的"点击截图"按钮
2. **框选区域**：有程序界面范围框点左键截图，或按住鼠标左键拖动选择区域
3. **完成截图**：松开鼠标左键，截图自动保存到剪切板

### 取色功能

- **鼠标悬停**：显示局部放大镜，可查看像素细节
- **右键操作**：右键点击可复制当前坐标和色值信息

### 其他功能

- **自动保存**：右键小图标勾选"自动保存"，截图自动保存到程序目录
- **开机自启**：右键小图标勾选"开机自启"，开机后自动启动
- **滚动截屏**：按住空格+左键框选，然后松开按键自动滚动截屏，屏幕截图预览框消失后自动复制或保存
- **截图后编辑**：右键小图标勾选"截图后编辑"，截图后进入编辑模式，可进行矩形框、画笔、文字标注

### 截图后编辑功能

编辑模式下提供以下工具：

- **矩形框**：点击后可在截图区域绘制矩形边框，支持调节粗细（滑块控制 1-10）
- **画笔**：点击后可自由绘制，支持调节粗细（滑块控制 1-10）
- **文字**：点击后在指定位置输入文字，支持调节字体大小（滑块控制 10-48）
- **颜色选择**：可选择 8 种预设颜色
- **撤销**：点击撤销按钮回退上一步操作
- **确认/取消**：点击确认按钮保存编辑结果并复制到剪贴板，或点击取消按钮放弃编辑

### 下载可执行exe
打包后的可执行文件位于 `dist/ScreenshotTool.exe`

## 项目结构

```
screenshot_tool/
├── main.py                 # 程序入口
├── screenshot_app.py       # 主界面应用类
├── capture_overlay.py      # 截图覆盖层（放大镜、取色等）
├── utils.py                # 工具函数（保存、剪贴板操作等）
├── build.py                # PyInstaller 打包脚本
├── requirements.txt        # 依赖列表
├── JT.ico                  # 程序图标
├── JT.png                  # 图标预览
└── dist/                   # 打包输出目录
    └── ScreenshotTool.exe  # 打包后的可执行文件
```


## 快速开始

### 安装依赖

```bash
pip install -r requirements.txt
```

## 程序主入口

```bash
python main.py
```

**打包命令**：
项目使用 PyInstaller 打包，可生成单文件可执行程序。
```bash
python build.py
```
